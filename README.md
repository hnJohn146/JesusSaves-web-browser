# JesusSaves v1.1.0 — Changelog

JesusSaves is a modified build of NetSurf 3.11 (GPLv2). NetSurf is the work of the NetSurf Developers; changes are by the JesusSaves project.

* **Search:** DuckDuckGo only (`https://html.duckduckgo.com/html/?q=%s`).
* **Home page and bookmarks:** KJV John 14:6 / Acts 4:12, DuckDuckGo form, Bible, evangelism (Billy Graham, christpath.org), Baptist and sound-teaching links. No prosperity-gospel sites.
* **DNS:** Pinned to `1.1.1.3` and `1.0.0.3` via c-ares; DoH fallback; fail closed; no option or preference can change it.
